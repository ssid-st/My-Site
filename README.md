# My-Site

Сайт-портфолио фотографа Stanislav Sydorov. Обычный статический сайт: HTML, CSS, немного JS, без сборщиков и серверной части. Подходит для любого хостинга, в том числе GitHub Pages.

## Структура

| Путь | Что там |
|---|---|
| `index.html`, `projects.html` … `contact.html`, `404.html` | Английская версия (корень сайта) |
| `de/`, `ru/` | Те же страницы на немецком и русском |
| `css/style.css` | Единый файл стилей, тёмная и светлая тема |
| `js/site.js` | Шапка, меню, переключатель темы, появление плиток |
| `js/hero.js` | Карусель на главной |
| `js/gallery.js` | Просмотр альбома: открытие из обложки, свайпы |
| `portfolio/<раздел>/<альбом>/` | Исходные фото в JPEG (до 1600 px, без EXIF и GPS) |
| `img/<раздел>/<альбом>/` | WebP-копии 800 и 1600 px и обложки 4:5, создаются скриптом |
| `tools/build.py` | Скрипт, который собирает все страницы и картинки |
| `ico/`, `icons/`, `images/` | Фавиконки, иконки соцсетей, фон страницы 404 |
| `vendor/bootstrap/` | Нужен только старым версиям в `versions/`, текущий сайт без него |

## Тексты и языки

Все тексты сайта на трёх языках лежат в словаре `T` в начале `tools/build.py`. Поправьте текст там и запустите скрипт. Названия альбомов задаются в `ALBUM_TITLES` (общие для всех языков) или в `T[язык]['albums']`.

## Обложки альбомов

Обложка берётся из первого фото альбома, у проектов из фото, похожего на старое квадратное превью. Чтобы выбрать другое фото, впишите его в `COVER_PHOTOS`, например `'beauty/kate': '03.jpg'`.

## Как добавить альбом

1. Положите фото в `portfolio/<раздел>/<новый-альбом>/` (латиница, без пробелов).
2. При желании впишите красивое название альбома в `ALBUM_TITLES` в `tools/build.py`.
3. Запустите `python3 tools/build.py` (нужен Pillow: `pip install Pillow`). Первый запуск создаёт WebP-копии, это пара минут, потом быстро.
4. Закоммитьте изменения.

Чтобы заново импортировать фото из папки с оригиналами (она уменьшит их, удалит EXIF/GPS и переименует по порядку):

```
python3 tools/build.py --src "путь/к/портфолио-оригиналам"
```

Страницы `*.html` генерируются скриптом, поэтому правки шапки, меню и подвала вносите в функцию `page()` в `tools/build.py`, а не в сами HTML-файлы.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`. `404.html` в корне подхватится автоматически.

## Версии сайта

Все варианты сайта сохранены и открываются со страницы `versions/index.html` (ссылка «Site versions» в подвале):

| Папка | Версия |
|---|---|
| корень сайта | Версия 3, текущая: тёмная тема, три языка, новый просмотр альбомов |
| `versions/v2-carousel/` | Версия 2: полноэкранная карусель, анимации |
| `versions/v3-concept/` | Концепт редизайна (только главная) |
| `versions/v1-cleanup/` | Версия 1: исправленный и дополненный сайт |
| `versions/v0-original/` | Исходный сайт 2021 года |

Фото у всех версий общие (`portfolio/`), копий нет.
Чтобы сохранить текущую версию перед новыми изменениями, скопируйте HTML, `css/` и `js/` в `versions/vN-название/`, поменяйте в HTML пути `portfolio/`, `ico/`, `icons/`, `vendor/`, `images/` на `../../…` и добавьте карточку в `versions/index.html`.
